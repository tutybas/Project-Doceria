# Doceria BenDoce

Projeto inicial de uma página HTML para a Doceria BenDoce. Atualmente, a página apresenta o nome da doceria e aplica estilos básicos ao fundo e ao título.

## Funcionalidades implementadas

| Funcionalidade | Descrição |
| --- | --- |
| Exibição do título | Apresenta “Doceria BenDoce” centralizado na página. |
| Estilo básico da página | Define o fundo rosa e centraliza o título usando CSS externo. |

## Sobre a organização do código

O conteúdo da página está em `SiteDoces.html`, que importa os estilos de `DocesEstilo.css`. Essa separação mantém a estrutura HTML e a apresentação visual em arquivos distintos, facilitando alterações independentes no conteúdo e no estilo.

## Estrutura visual planejada

O README anterior descreve a intenção de criar um fundo estático com uma área central deslizante, contendo produtos apresentados em cartões no estilo polaroide e organizados em um carrossel. Esses elementos ainda não estão implementados nos arquivos atuais.

## Aprendizados aplicados

- Estrutura básica de um documento HTML.
- Inclusão de uma folha de estilos externa com `<link>`.
- Uso de CSS para definir a cor de fundo e alinhar texto ao centro.
